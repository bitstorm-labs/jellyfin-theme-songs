Themes are saved as theme.mp3 inside each series folder, so Jellyfin needs write access to your TV library. Sources come from tvthemes.plexapp.com — a free third-party service covering TV series only, with gaps for very recent shows. Series without a TVDB ID are skipped, and an existing theme.mp3 is never overwritten.

Shows with no theme available are retried on this interval.

When it runs

A scheduled task, Download theme songs, sweeps every TV series in your libraries nightly at 3:00 AM. You can run it any time from Dashboard → Scheduled Tasks. With the option below enabled, a newly added series is also looked up immediately instead of waiting for the next sweep. Both paths do exactly the same work.

What happens for each series

  1. Already has a theme? Skip it. A file you placed yourself always wins.
  2. Find its TVDB ID. The theme source is keyed by TVDB, so a series without one — a YouTube channel imported as a series, for instance — is skipped silently rather than logged as a failure.
  3. Check recent history. If this series was looked up recently and had no theme, it is left alone until the retry interval below has passed.
  4. Download from tvthemes.plexapp.com, throttled to about one request per second so a large first sweep stays polite to a free service.
  5. Validate before writing. A missing theme comes back as a small HTML error page, not a 404 file. Without checking, that page would land on disk named theme.mp3 and every client would try to play it. The download must be a real MP3, of plausible size, or it is discarded.
  6. Write atomically — to a temporary file, then rename into place — so a download interrupted by a restart cannot leave a half-written file that looks valid.
  7. Refresh the item. Jellyfin does not notice a new theme.mp3 on its own; without this step the file is on disk but nothing will play it. The theme usually appears within a few seconds, occasionally a minute or two.

When a theme cannot be found

If the service genuinely has no theme for a series, that is remembered and retried on the interval below — themes do get added for newer shows, so it is worth asking again occasionally, just not every night. A temporary problem (server error, timeout, a download that fails validation) is deliberately not remembered, so a bad hour upstream cannot mark your whole library as themeless until the interval expires.

What it never does

  • Overwrite an existing theme.mp3.
  • Write anything it has not validated as a playable MP3.
  • Touch movies or music — TVDB IDs are television-only.
  • Delete or move any of your media.

Where the files go

Alongside your episodes, as <series folder>/theme.mp3 — the location Jellyfin's built-in theme playback looks in. Playback itself is a client setting: in Jellyfin web it is Settings → Playback → “Play theme songs”.
