Saves themes as theme.mp3 in each series folder, so Jellyfin needs write access to your TV library. Sources come from tvthemes.plexapp.com — free, TV only, with gaps for very recent shows. An existing theme.mp3 is never overwritten.

Shows with no theme available are retried on this interval.

Runs nightly at 3:00 AM as the Download theme songs scheduled task, and optionally the moment a series is added. Run it any time from Dashboard → Scheduled Tasks.

For each series:

  1. Skip if a theme.mp3 is already there.
  2. Look up its TVDB ID — no ID, no lookup.
  3. Skip if it failed recently (see the retry interval).
  4. Download, throttled to about one request per second.
  5. Validate it is a real MP3 — a missing theme returns an error page, not a 404.
  6. Write to a temp file, then rename it into place.
  7. Refresh the item, or Jellyfin never notices the file.

A theme that genuinely does not exist is retried on your interval below. Temporary failures — timeouts, server errors — are not recorded, so a bad hour upstream does not stall your whole library.

Files land at <series folder>/theme.mp3. Playback is a client setting: Settings → Playback → “Play theme songs”.
